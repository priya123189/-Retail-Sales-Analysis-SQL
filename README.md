# 🛍️ Retail Sales Analysis using SQL

## 📌 Project Overview
This project analyses retail sales transaction data using SQL to extract meaningful business insights.
The dataset includes details such as product categories, quantity sold, pricing, total sales amount, and customer demographics (age and gender).
The analysis focuses on understanding overall sales performance, identifying top-performing product categories, analysing customer purchasing behaviour, and uncovering monthly sales trends. 
This project demonstrates practical SQL skills required for entry-level Data Analyst roles.

## 🎯 Project Objectives
- Analyse overall retail sales performance using SQL
- Identify top-performing product categories
- Understand sales trends over time
- Analyse customer purchasing behaviour by age and gender
- Generate insights to support data-driven business decisions

## 🗂 Dataset Overview
Each record represents a single retail transaction.

**Key Columns:**
- Transaction_ID – Unique transaction identifier  
- Date – Date of purchase  
- Gender – Customer gender  
- Age – Customer age  
- Product_Category – Product category  
- Quantity – Units sold  
- Price_Per_Unit – Price per unit  
- Total_Amount – Total transaction value  

## 🛠 Tools & Skills Used
**Tools:**
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Microsoft PowerPoint

**SQL Skills:**
- Data Import (CSV to SQL Table)
- WHERE, GROUP BY, ORDER BY
- Aggregate Functions (SUM, COUNT, AVG)
- CASE WHEN for age categorisation
- Date-based Analysis
- Data Cleaning & Validation

## 📊 Key Analysis & Insights
- **Total Revenue:** 456,000
- **Top Product Category:** Electronics
- **Gender-wise Sales:** Female customers contributed slightly higher revenue
- **Age Group Performance:** Highest sales from 34–55 age group
- **Monthly Trend:** February recorded the highest sales

## 💡 Business Recommendations
- Focus on Electronics and Clothing categories
- Improve Beauty category sales using discounts and bundles
- Target female customers with personalised campaigns
- Focus marketing on the 34–55 age group
- Plan promotions during high-performing months

## 📈 Project Impact
- Delivered clear insights into retail sales performance
- Identified key customer segments and product categories
- Supported better sales forecasting and marketing decisions
- Demonstrated strong foundational SQL and analytical skills
